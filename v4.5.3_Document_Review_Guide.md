# CCI v4.5.3 — focused document review (billing account)

**Purpose:** Re-run **document-level analysis**, not the completed v4.5.2 cost-line confidence pass. No Google Sheet reset, extra tabs, personal-script replacement, redeployment, or API-key change.

## 1. Install carefully

1. In the **existing billing-account** Apps Script project, run `removeBillingTriggersV45()` to pause the scheduled live and history triggers for the swap. Finish/stop a currently executing backfill first.
2. Replace the **entire existing billing `Code.gs`** with `CCI_v4_5_3_Billing_Document_Review.gs`. Do **not** paste the code below the previous v4.5.2 file (that would duplicate functions). Save.
3. Keep Script Properties `SPREADSHEET_ID`, `OPENAI_API_KEY`, and `BILLING_GMAIL_ADDRESS` unchanged. Keep your current master Google Sheet, job labels, existing source ledger, and manual quantity entries. No `reset...` or `deploy` step.
4. In master Sheet's `Settings`, use `MIN_CLASS_CONFIDENCE=0.80` and `MIN_RATE_CONFIDENCE=0.80`; `SIMILARITY_REVIEW_THRESHOLD=0.75` is used by the original incoming-document matching routine. The new document-review engine also compares priced lines at a 0.75 similarity threshold. **75% resemblance means compare, not merge or count a second expense.**

## 2. Diagnose the two analysis errors **first**

Run `diagnoseDocumentAnalysisErrorsV453()` from the billing script editor and inspect its execution log. It reads the `Source Ledger` and `Review Queue` without changing anything or calling OpenAI.

- `sourceErrors` counts ledger entries with `State=ERROR`, with filename/attempt/error text.
- `analysisReviews` counts open review entries mentioning processing, analysis, API or extraction errors.
- If the failure was unsupported `.xlsx/.xls` input, corrupted PDF, API 400, missing permissions, or malformed output, **do not** blindly retry every error; examine the exact error text first. This update's original-source re-analysis supports PDF, PNG, JPEG, WebP, and qualifying email bodies, but doesn't convert Office attachments.
- Existing `retrySourceErrorsV45()` changes *all* failed ledger sources to `RETRY`; it does not itself run the historical scanner. Use only after resolving the reported cause and restarting source coverage as needed.

The diagnostic is not a guarantee that every past issue has been recovered. Copy the two exact error messages if they remain.

## 3. Run one document-review batch

1. Run `previewDocumentReviewV453()` — returns up to six candidate documents, sourced from `SUPPORTING`, `HELD_REVIEW`, or `HELD_DUPLICATE` documents **with priced lines**. The preview makes no AI calls or edits.
2. Run `reviewDocumentBatchV453()` — re-reads the original source (where available), queries OpenAI **once per selected source**, checks project/vendor/transaction references and item-level costs, and applies only defensible changes. It uses up to six documents per batch, with a time guard.
3. Inspect the log fields `promoted`, `copies`, `newLines`, `errors`, and `items` before continuing.
4. Repeat `reviewDocumentBatchV453()` until `complete: true`. It stores its own progress cursor in billing Script Properties and **does not loop back** to the beginning after finishing.
5. `restartDocumentReviewV453()` explicitly starts this review over at the top. It **does not** clear any invoices. Use only after you have examined results or changed the document-review rules. Existing lines are checked by ID/amount before adding new ones.

### Safe outcomes

- **Actual invoice/receipt, confidently evidenced, unrelated to another counted transaction:** May be reclassified `COUNTED` and included in expense totals. Purchase amount is counted once.
- **Clearly identified duplicate of another counted purchase:** `COPY`, cost impact $0.
- **Priced delivery confirmation, packing slip, order acknowledgement, quote, estimate:** Remains `SUPPORTING`, cost impact $0. Valid quantities and costs become **`[REFERENCE]`** rows in `Price History` (not booked spending, `Auto_Use=NO`).
- **Changed prices, revised totals, uncertain references, competing project matches:** Kept on hold for review rather than summed as another purchase.
- **Missing source or OpenAI error:** Logged as `Document re-analysis error` in Review Queue. The batch continues to the next document. The existing data is not deleted.
- **Missing quantity or unit:** The original line remains cataloged in Cost Lines; a mathematically defensible unit rate cannot be created until quantity/unit are known.

## 4. Rebuild price history and verify

`reviewDocumentBatchV453()` refreshes Price History after a nonempty applied batch. You can also run `refreshPriceHistoryV45()` manually.

Check `Documents`: correct `Doc_Type`, `Status`, `Cost_Impact` and source link. Check `Cost Lines`: line amounts, descriptions, quantities, and manual corrections. Check `Price History`: `RATE-` rows are verified purchases; `REFRATE-` rows have `[REFERENCE]` in the item name and `Auto_Use=NO` (provisional only). Check `Review Queue`: any conflicting revised invoices or repeated analysis errors should be inspected.

**Note:** This pass does not reconstruct every lost historical line if the source is inaccessible or the AI could not extract it. It doesn't add the price difference of a corrected invoice as a second purchase; it flags that situation to avoid double-counting.

## 5. Restore normal mail processing

Once one batch is verified, run `installBillingTriggersV45()` to restore the existing live 15-minute trigger and, **if** `HISTORY_ENABLED=YES`, the hourly backfill trigger. If you want to leave history paused, set `HISTORY_ENABLED=NO` before installing. Do not click Deploy.

## What changed compared with v4.5.2?

- Added five functions: `diagnoseDocumentAnalysisErrorsV453`, `previewDocumentReviewV453`, `reviewDocumentBatchV453`, `restartDocumentReviewV453`, and internal original-source matching helpers.
- Kept the proven billing Gmail links, 30-line eligibility recheck, existing labels, invoice processing, source ledger, and all Google Sheet tab/column names.
- Improved future intake prompts so a priced attachment isn't discarded just because the email subject refers to delivery; financial evidence still decides whether it is a charge.
- Preserved provisional unit-price information from supporting documents, separated from actual confirmed costs in the **same** Price History tab.
